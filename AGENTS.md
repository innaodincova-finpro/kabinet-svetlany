# Инструкция для работы с Кабинетом Светланы

Перед работой прочитать PROJECT_STATUS.md и относящиеся к текущему поручению план и приёмку. Актуальные границы этапа находятся в PROJECT_STATUS.md.

Работать только с innaodincova-finpro/kabinet-svetlany — «Кабинет Светланы». Отдельные проекты «Светлана №1», «Светлана №2» и демоверсию не изменять.

На текущем этапе 2 октября 2026 исправляются только три заявленных замечания Светланы. Это ограничение текущего этапа, не постоянное ограничение дальнейшей работы. Последующие задачи определяются новыми поручениями Инны. Исторические списки не расширяют текущее поручение. Старые три замечания PR #14 не подменяют текущие.

Не подменять требование автоматического содержательного комментария механической сборкой текста. Не менять реальные данные и не публиковать персональные данные. Бахруз и реальное «оплачено 0» исключены из текущего разрешённого выпуска.

Проверять существующую логику, влияние на связанные разделы, сохранность, компьютерную и мобильную версии, точный коммит и опубликованную версию. Не выдавать локальные проверки за проверку устройства Светланы или OneDrive. Закрывать задачи по доказательствам. Отчёт: сделано / не сделано / дальше, актуальная ссылка после проверки публикации.
